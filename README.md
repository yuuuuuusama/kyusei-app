# 干支九星気学 鑑定アプリ

iPhone / Mac の Safari で動く PWA (Webアプリ)。
鑑定書・判断書の作成、履歴保存、PDF出力に対応。

## 機能

- **入力欄**: iOS の設定画面と同じグループ化リスト。「相談者」「相談」「自動で出るもの」に分け、
  自分で書く欄と計算で出る欄を混ぜない。性別はセグメント、相談日の「今日」は行内の小ボタン
- **和暦入力**: 生年月日・相談日とも、元号+和暦年でも西暦でも入力でき、双方向に同期。
  改元は年の途中なので月日まで見て判定する (1989年1月7日=昭和64年 / 1月8日=平成元年)
- **自動計算**: 生年月日と相談日から
  - 年・月・日・時の干支 (節入り境界考慮)
  - 本命星・月命星
  - 8つの盤 (相談日 年月日時 + 生年月日時)
  - 後天定位による方位配置
  - 本命宮・対冲宮・右宮・左宮・本宮・中宮
  - 解決宮・時本命宮・時本宮宮
  - 年同会・被同会、月同会・被同会
  - 宮傾斜
  - 流年法 60年早見
  - 解神 (12支対応)
- **詳細鑑定の絞り込み**: 全31項目を 命式 / 運気 / 方位 / 開運 / 相性 / 暦 / 道具 の7分類に整理。
  分類タブとキーワード検索で目的の項目へ直接たどり着ける (検索は分類をまたいで探す)。
  選んだ分類は次回起動時も保持。印刷時は絞り込みを無視して全項目を出力
- **手書きフィールド**: 内蔵・宿命・相談事情・本人運気・総合判断
- **データ保存**: 端末のブラウザに保存。エクスポート/インポート可能
- **PDF出力**: 印刷メニューから PDF として保存可能 (A4縦)

## 起動方法

### Mac で開発・確認

ファインダで `start.command` をダブルクリック。
ブラウザが起動し `http://localhost:8765/` でアプリが開きます。

### iPhone で利用 (同じWi-Fi)

1. Mac で `start.command` を起動
2. iPhone の Safari で表示される URL を開く
   例: `http://192.168.11.57:8765/`
3. **共有 → ホーム画面に追加**

ホーム画面のアイコンから起動すると、Safari の UI なしで全画面表示されます。

### 常時オンラインで使う (推奨: GitHub Pages 等で公開)

このフォルダごと公開すれば、Mac を立てていなくても iPhone から利用可能。

```
cd ~/kyusei-app
git init && git add . && git commit -m "init"
# GitHub に push 後、Settings → Pages から公開
```

## 計算方式の出典

- **節入り**: Meeus "Astronomical Algorithms" Ch.25 の太陽視黄経公式 + 二分法。1900〜2100年で誤差約数分。
- **年盤本命星**: 11 - (西暦の各桁を一桁になるまで足した数)、立春境界
- **月盤本命星**: 年支の三合グループ (子卯午酉=寅月八白 / 丑辰未戌=寅月五黄 / 寅巳申亥=寅月二黒) から月支offsetで-1ループ
- **日盤本命星**: 冬至/夏至直近の甲子日を起点に、陽遁(+1) / 陰遁(-1)
- **時盤本命星**: 日支の三合グループ + 時支offset + 陽遁/陰遁
- **干支**: 1900-01-01 = 庚子日 を基準として連続日カウント

## 注意事項

- 計算は分単位の節入り精度で日付判定しますが、節入り当日の境界付近(±数分以内)は伝統的な暦表で確認することをお勧めします
- 「解決宮」「右宮」「左宮」「内蔵法」「宮傾斜」の解釈は流派により異なります。本アプリでは標準的な定義を採用していますが、必要に応じてテキスト欄で手動補正してください
- 本命星 = 五黄 の方は「対冲宮」が中央となるため一部の欄が表示されません

### 鑑定の記録について

**記録は各自のブラウザ（localStorage）にだけ残る。** 公開先へは送られない。
URL を知らせても、他人の鑑定記録は見えない。
別の端末へ引き継ぐ仕組みは無いので、記録は端末ごとに独立している。

### 載せないもの

`.assetsignore` で次を除いてある。

- `_misc/` と `*.pdf` … 早見表・四盤暦・宮傾斜象意。他所の資料を写したもので、
  アプリからは読み込んでいない（出典の注釈に名が出るだけ）。
  公開すると権利の問題になり得るので手元に留める。
- `start.command` … Mac で手元のサーバを立てるためのもの。公開先では要らない。

手元だけで使うときは、これまでどおり `start.command` をダブルクリックすればよい。
