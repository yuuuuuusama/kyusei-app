# App Store への申請

iPhone アプリ「九星鑑定」を App Store（まず TestFlight）へ出すための控え。
App Store Connect に打ち込む文言と、出す前に見ることをまとめてある。

## 出し方

```bash
python3 scripts/generate_ios_project.py   # ソースや版を変えたときだけ
scripts/archive.sh                        # 組んで build/export/ に .ipa を作る
scripts/archive.sh --upload               # 組んで、そのまま App Store Connect へ送る
```

- 組み番号は日時から自動で付く（送るたびに違う番号が要るため）
- 表に出る版（1.0）は `scripts/generate_ios_project.py` の `MARKETING_VERSION`
- 組んだ束は `scripts/check-bundle.sh` で自動的に検める（元資料が入っていないこと等）

## 出す前に見ること

- [ ] Apple Developer Program（チーム P7442B37HP）が有効
- [ ] App Store Connect に「新規 App」を作ってある（Bundle ID `jp.myodenji.kyusei`）
- [ ] Web 側の試験が通る
      `node scripts/test-privacy.mjs` / `node scripts/test-storage.mjs`
      （Mac 以外は `CHROME=<Chrome の道>` を付ける）
- [ ] 実機で器の自己確認が通る（スキームの引数に `-kyusei.selfCheck YES`）
- [ ] 実機で見え方を確かめる（シミュレータは絵文字が豆腐になる）
- [ ] 錠（Face ID／パスコード）が掛かり、外せる
- [ ] 書き出し → 共有の板 → ファイルへ保存 → 取り込み、で記録が戻る
- [ ] 公開先の `privacy.html` が開ける（下の「プライバシーポリシー URL」）
- [ ] スクリーンショットを撮る（下）

### 説明文

```
干支九星気学による鑑定書・判断書を、iPhone ひとつで作るためのアプリです。

生年月日と相談日を入れるだけで、次のものを自動で出します。
・年・月・日・時の干支（節入りを考えて判定）
・本命星・月命星

命式・運気・方位・開運・相性・暦・道具の七つに分けた詳細鑑定を、

・記録はこの iPhone の中だけに残ります。どこへも送りません

生年月日・相談日は和暦（元号）でも西暦でも入れられます。
```

### App のプライバシー（栄養成分ラベル）

**「データを収集していない」** を選ぶ。

- 入力は端末の中だけに残り、当方へは送らない
- 広告・解析・追跡の仕組みを持たない（`PrivacyInfo.xcprivacy` と一致）
- 🎤 の音声は Apple の音声認識へ送られるが、これは Apple が処理するもので、
  開発者が受け取る「収集」には当たらない（`privacy.html` 四にも明記）

### 輸出コンプライアンス

`ITSAppUsesNonExemptEncryption = NO` を Info.plist に入れてあるので、送るたびの問いは出ない。

```

ネイティブの機能として、Face ID による錠、共有シートへの書き出し、
端末内での記録の永続保存を備えています。
```
